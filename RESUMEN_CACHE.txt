🎯 FUNCIONALIDADES DEL SISTEMA DE CACHÉ
═══════════════════════════════════════════════════════════════════════════════

FUNCIONES BÁSICAS:
✅ setCache(key, data, ttl)                - Guardar datos con expiración
✅ getCache(key, options)                  - Recuperar datos válidos
✅ hasCache(key)                           - Verificar si existe
✅ deleteCache(key)                        - Eliminar entrada específica
✅ clearExpiredCache()                     - Limpiar expirados
✅ clearAllCache()                         - Limpiar todo
✅ getCacheStats()                         - Estadísticas del caché

FUNCIONES OFFLINE:
✅ getCacheWithOfflineSupport(key)         - Datos con soporte offline
✅ fetchWithCache(key, fn, options)        - Wrapper con caché automático

FUNCIONES DE API:
✅ fetchWeatherCached(lat, lon)            - Clima por coordenadas
✅ getCityWeatherInfoCached(city)          - Clima por ciudad
✅ getMultipleCitiesWeatherCached(cities)  - Múltiples ciudades
✅ preloadCitiesWeather(cities)            - Pre-cargar ciudades
✅ checkCityWeatherCache(city)             - Verificar estado
✅ refreshCityWeather(city)                - Forzar actualización

💡 EJEMPLOS DE USO
═══════════════════════════════════════════════════════════════════════════════

1. USO BÁSICO:
   const result = await getCityWeatherInfoCached('Bogotá');
   if (result.success) {
     console.log(result.data.temperature);
   }

2. FORZAR ACTUALIZACIÓN:
   const result = await getCityWeatherInfoCached('Bogotá', {
     forceRefresh: true
   });

3. MÚLTIPLES CIUDADES:
   const cities = ['Bogotá', 'Medellín', 'Cali'];
   const results = await getMultipleCitiesWeatherCached(cities);

4. PRE-CARGAR:
   const stats = await preloadCitiesWeather(['Bogotá', 'Medellín']);
   console.log(`Pre-cargadas: ${stats.success}/${stats.total}`);

5. VERIFICAR CACHÉ:
   const info = checkCityWeatherCache('Bogotá');
   if (info) console.log('Hay datos en caché');

6. ESTADÍSTICAS:
   const stats = getCacheStats();
   console.log(`Total: ${stats.total}, Válidas: ${stats.valid}`);
