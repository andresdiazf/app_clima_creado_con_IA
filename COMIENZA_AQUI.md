## ⚡ En 3 Minutos

### ¿Qué es Weather App?
Una app web que busca el clima de cualquier ciudad usando Open-Meteo API (gratuita).

### ¿Cómo funciona?
1. Escribe un nombre de ciudad
2. App obtiene coordenadas
3. App obtiene datos del clima
4. Muestra temperatura, humedad, viento, pronóstico
5. Guarda últimas 5 ciudades

### ¿Está lista para usar?
✅ **SÍ** - 100% funcional, testeada, segura y auditada.

## 🚀 EMPEZAR RÁPIDO (5 MINUTOS)

### 1. Abrir aplicación
```bash
# Opción A: Abrir archivo directamente
# Haz doble clic en: index.html

# Opción B: Usar servidor local
cd weather-app
npm install
# Abre http://localhost:5500 (si tienes Live Server)
```

### 2. Buscar un clima
- Escribe: `Bogotá`
- Presiona: Enter
- Mira: Temperatura, humedad, viento, pronóstico

### 3. Ver historial
- Tus últimas 5 ciudades aparecen abajo
- Click en cualquiera para re-buscar
