PASO 2: PROBAR CACHÉ BÁSICO
═══════════════════════════════════════════════════════════════════════════════

A. PRIMERA BÚSQUEDA (Sin caché)
   1. Escribe "Bogotá"
   2. Presiona Enter
   3. Resultado: Datos se cargan (tarda ~1 segundo)

B. SEGUNDA BÚSQUEDA (Con caché)
   1. Borra el campo
   2. Escribe "Bogotá" de nuevo
   3. Presiona Enter
   4. Resultado: ⚡ INSTANTÁNEO + mensaje "📦 Datos del caché"

PASO 5: VER DATOS EN LOCALSTORAGE
═══════════════════════════════════════════════════════════════════════════════

1. En DevTools, click en pestaña "Application"
2. Panel izquierdo → Local Storage
3. Click en tu dominio (file:// o localhost)
4. Busca claves que empiecen con "weather_cache_"

PASO 6: COMANDOS ÚTILES EN CONSOLA
═══════════════════════════════════════════════════════════════════════════════

A. VER ESTADÍSTICAS DEL CACHÉ
   En Console, pega este código:

   import { getCacheStats } from './src/utils/cache.js';
   const stats = getCacheStats();
   console.log('Total:', stats.total);
   console.log('Válidas:', stats.valid);
   console.log('Expiradas:', stats.expired);
   console.table(stats.entries);

B. VER EDAD DEL CACHÉ
   const item = localStorage.getItem('weather_cache_city_bogota');
   const entry = JSON.parse(item);
   const age = (Date.now() - entry.timestamp) / 1000;
   console.log(`Edad: ${Math.floor(age)} segundos`);

C. LIMPIAR TODO EL CACHÉ
   import { clearAllCache } from './src/utils/cache.js';
   clearAllCache();
   console.log('✅ Caché limpiado');

D. VER TODAS LAS CLAVES DE CACHÉ
   Object.keys(localStorage)
     .filter(k => k.startsWith('weather_cache_'))
     .forEach(k => console.log(k));

🐛 PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: No aparece "📦 Datos del caché"
SOLUCIÓN: Verifica que index.html use src/app.cached.js

PROBLEMA: Modo offline no funciona
SOLUCIÓN: Marca el checkbox "Offline" en Network

PROBLEMA: No veo datos en localStorage
SOLUCIÓN: Ve a Application (no Console) → Local Storage

PROBLEMA: El caché no expira
SOLUCIÓN: Espera 10 minutos o cambia DEFAULT_TTL a 10 segundos
